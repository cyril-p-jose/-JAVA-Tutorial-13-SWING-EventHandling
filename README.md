# Tutorial 14: Swing GUI and Event Handling in Java

This repository contains Java Swing GUI implementations for **Tutorial 14** of the Object-Oriented Programming (OOP) course. The tutorial focuses on building graphical user interfaces, managing component layouts, and implementing event handlers using `ActionListener`.

## 📝 Questions & Program Descriptions

### Question 1: Fibonacci Series Generator
* **Goal:** Display Fibonacci numbers up to a specified limit in a `JList` component with event handling and clear capabilities.
* **Key Components:** `JTextField`, `JList`, `DefaultListModel`, `JScrollPane`, `JButton` (`Generate`, `Clear`).

---

### Question 2: Factorial Calculator
* **Goal:** Calculate and display the factorial of a user-entered number using GUI controls.
* **Key Components:** `JTextField` (Input & Output), `JButton`, `ActionListener`.

---

### Question 3: Feet and Inches to Centimeters Converter
* **Goal:** Convert height/length from feet and inches into centimeters ($1\text{ inch} = 2.54\text{ cm}$).
* **Key Components:** `JTextField` (Feet, Inches, CM Output), `JButton` (`Convert to CM`).

---

### Question 4: Prime Number Checker
* **Goal:** Determine whether a user-provided integer is a prime number.
* **Key Components:** `JTextField`, `JButton` (`Check Prime`), `ActionListener`.

---

### Question 5: Previous and Next Number Generator
* **Goal:** Accept an integer input and display its previous ($n - 1$) and next ($n + 1$) values across three separate text fields upon clicking a button.
* **Key Components:** 3 `JLabel` components, 3 `JTextField` components, 1 `JButton`.

## 🚀 How to Run in Eclipse

1. **Open Eclipse** and select your workspace.
2. Create a new Java Project:
   * **File** ➔ **New** ➔ **Java Project**
   * Project Name: `Tutorial14`
3. Add source files:
   * Right-click `src` ➔ **New** ➔ **Class**.
   * Create files `Question1.java` through `Question5.java`.
4. **Run the Programs**:
   * Open any file and press `Ctrl + F11` (or click the green **Run** button).
   * Interact with the graphical interface window that pops up.
